Privacy Policy

Last updated: June 7, 2026

This Privacy Policy applies to the 划词翻译 Chrome extension ("the Extension").

Data Collection

The Extension collects the following data exclusively for its core functionality:

  • Selected text — When you select text on a webpage and click the translate button, the selected text is sent to the AI translation API endpoint you configured.
  • API configuration — Your API endpoint, API key, model name, and language preferences are stored locally in your browser using chrome.storage.sync.

Data Storage

All configuration data (API key, endpoint, model, preferences) is stored locally in your browser via Chrome's built-in storage API. The Extension does not operate its own servers and does not transmit any data to the Extension developer.

Data Transmission

Selected text is transmitted only to the API endpoint you configure (e.g., OpenAI, DeepSeek, or any OpenAI-compatible service). The Extension developer has no access to your selected text, API key, or translation results. All API communication uses HTTPS encryption.

Data Sharing

The Extension does not sell, share, or transfer any user data to third parties. The Extension developer does not collect, store, or have access to any user data.

User Control

You may update or clear your API configuration at any time through the Extension's settings page. Translation is triggered only when you explicitly click the translate button after selecting text. You can uninstall the Extension at any time, which removes all locally stored data.

Contact

If you have questions about this Privacy Policy, please open an issue at https://github.com/ZephyRTy/selection-translator.
