# 划词翻译 (Selection Translator)

选中文本，点击翻译 —— 一款简洁高效的 AI 划词翻译 Chrome 插件。告别繁琐的复制粘贴到翻译网站，只需在网页上选中文字，点击浮出的翻译图标，即可获得高质量 AI 译文。

## 为什么选择划词翻译？

传统的网页翻译方式需要复制文字、打开新标签页、粘贴到翻译网站、等待结果……整个过程打断了你的阅读节奏。划词翻译将这一切简化为两个动作：**选中 → 点击**，翻译结果以优雅的浮动弹窗呈现在原文旁边，无需离开当前页面。

与依赖固定翻译引擎的插件不同，划词翻译完全由你自己掌控翻译质量。通过接入 OpenAI 兼容的大语言模型 API，你可以使用 GPT-4o、DeepSeek、通义千问等前沿 AI 模型进行翻译，翻译结果自然流畅，能准确理解上下文和习语，远超传统机器翻译的生硬质量。

## 核心功能

- **划词触发，按需翻译** — 选中任意网页文字后，选区旁边浮出翻译图标；点击图标才开始翻译，不会干扰你的正常阅读和编辑操作
- **AI 驱动的高质量翻译** — 基于 OpenAI Chat Completions API，支持 GPT-4o、DeepSeek、通义千问等所有兼容接口，翻译结果自然准确，能理解上下文语境和专业术语
- **完全自定义的 API 配置** — 支持填写你自己的 API Endpoint、Key 和 Model，用谁的 API、花多少钱、选什么模型，全部由你决定
- **多语言目标翻译** — 支持 10 种目标语言：中文、English、日本語、한국어、Français、Deutsch、Español、Português、Русский、العربية，源语言自动检测
- **自定义翻译风格** — 可编辑 System Prompt，自由调教翻译语气和风格，无论是直译、意译还是学术风格，你说了算
- **一键复制译文** — 翻译弹窗内置复制按钮，点击即可将译文复制到剪贴板
- **隐私绝对安全** — API Key 仅保存在你的浏览器本地（chrome.storage.sync），选中文本直接发送到你配置的 API 端点，插件开发者无法获取、存储或查看你的任何数据。全部代码开源透明，欢迎审查
- **轻量无广告** — 安装包仅 10KB，无追踪、无广告、无后台请求，永远免费

## 使用方法

1. 安装插件后，右键点击工具栏中的插件图标，选择「选项」进入设置页面
2. 填写你的 API 信息：Endpoint（如 https://api.openai.com/v1）、API Key、Model（如 gpt-4o-mini）、目标语言
3. 在任意网页上用鼠标选中你想翻译的文字，选区旁边会出现一个紫色翻译图标
4. 点击翻译图标，AI 译文会以弹窗形式展示在原文下方
5. 点击「复制」按钮一键复制译文，点击弹窗外部或按 ESC 关闭

## 支持的 API 服务

所有兼容 OpenAI Chat Completions 格式的服务均可使用，包括但不限于：
- OpenAI（GPT-4o、GPT-4o-mini、GPT-4 等）
- DeepSeek（deepseek-chat、deepseek-reasoner）
- 阿里云通义千问
- 智谱 GLM
- Moonshot（月之暗面）
- 硅基流动 SiliconFlow
- 任何自部署的 OpenAI 兼容 API（如 Ollama、vLLM、One API）

## 隐私承诺

本插件是一个纯客户端应用，没有任何自有服务器。你的 API Key 存储在你浏览器的本地存储中，选中的文本通过 HTTPS 加密直接发送到你配置的 API 提供商。插件的开发者无法获取、也不会获取你的 API Key、翻译内容和浏览数据。我们认为隐私不是附加功能，而是基本权利。
