# 划词翻译 (Selection Translator)

一款简洁高效的 AI 划词翻译 Chrome 插件。在网页上选中文字 → 点击翻译图标 → 弹窗展示 AI 译文，三步完成翻译，无需离开当前页面。

## 核心功能

- **划词即译** — 选中文字后浮出翻译图标，点击翻译，操作顺畅不打扰阅读
- **AI 驱动** — 基于 OpenAI Chat Completions API，支持 GPT-4o、DeepSeek、通义千问等所有兼容接口，翻译质量自然准确
- **灵活配置** — 支持自定义 API Endpoint、Key、Model 和翻译风格提示词，完全由你掌控
- **多语言支持** — 覆盖中英日韩法等 10 种目标语言，源语言自动检测
- **隐私安全** — API Key 仅存本地，选中文本直发你配置的 API，开发者无任何数据访问权限
- **轻量免费** — 安装包仅 10KB，无广告、无追踪、永远免费，全部代码开源

## 快速上手

1. 打开插件选项，填写你的 API 配置
2. 任意网页选中文字
3. 点击浮出的翻译图标即可获得译文，支持一键复制

适用于阅读外文文档、论文、新闻等所有需要快速翻译的场景。
