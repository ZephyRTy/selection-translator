# 划词翻译 (Selection Translator)

选中文本，点击翻译 —— 一款使用 AI 翻译的 Chrome 划词翻译插件。

## 功能

- **划词触发** — 在网页选中文字后弹出翻译图标，点击即译，不打扰阅读
- **AI 翻译** — 基于 OpenAI Chat Completions API，翻译质量远超传统机翻
- **自定义 API** — 支持 OpenAI、DeepSeek、通义千问等所有 OpenAI 兼容接口，完全由你掌控
- **多语言目标** — 支持中/英/日/韩/法/德/西/葡/俄/阿等 10 种目标语言
- **隐私优先** — API Key 仅存储在本地浏览器，选中文本直发你配置的 API，开发者无法获取任何数据

## 使用

1. 安装后在插件选项中配置 API（Endpoint、Key、Model）
2. 在任意网页选中文字
3. 点击浮出的翻译图标
4. 弹窗显示译文，支持一键复制
